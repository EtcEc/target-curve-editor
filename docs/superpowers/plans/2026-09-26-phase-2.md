# Phase 2 (design files, compare slots, chart handles) Implementation Plan

> Executed inline, test-first, in one session. Spec: `docs/superpowers/specs/2026-09-25-flexible-target-design.md` (UI, Phase 2 paragraph).

**Goal:** Save/load a design as a JSON file, keep three compare slots drawn faintly on the chart, and drag band handles on the chart. Plus the small dialog fixes left over from the guided layout.

**Architecture:** Pure modules (`designFile.ts`, `slots.ts`, `handles.ts`) hold all logic and are unit tested. The UI wiring (`designUi.ts`, chart handle DOM in `chart.ts`) stays thin and is checked in a browser.

## Global Constraints

- No new dependencies; the repo is public, so no personal data or real files in tests or commits.
- A design file is `{ "version": 1, "name": string, "bands": Band[], "cancelRolloff": boolean }`. The rolloff type is NOT in it (it comes from the loaded .ady).
- A design file is validated with `validateBands` before it is applied; a bad file changes nothing and shows a message.
- Compare slots hold a copy of the bands only; they are drawn with the current rolloff settings. The download always uses the active (editable) design.
- Handles exist for shelf and bell bands only (a tilt has no single point to drag). Dragging changes frequency and gain; the mouse wheel over a handle changes Q. The chart y-range stays -15..15 dB.

## Tasks

1. **designFile.ts**: `serializeDesign`, `parseDesign`, `designFilename`; tests for round trip, rejection of bad JSON / wrong version / bad bands / missing fields.
2. **Design file UI**: name field, Save design, Load design file input in the band toolbar; loading sets bands, name and the cancel checkbox.
3. **slots.ts + chart series**: `SlotStore` (save, clear, get), chart draws filled slots as faint lines; UI rows A/B/C with Save here / Load / Clear.
4. **handles.ts**: `handleFor(bands, index, offset)`, `dragBand(bands, index, freq, chartDb, offset)` (exact: gain = k * (target - other bands)), `scaleQ`; tests.
5. **Chart handles**: DOM handles inside the uPlot overlay, pointer drag, wheel-Q, repositioned on every update.
6. **Dialog fixes**: wording, sticky Close, headings above the two step-3 tables, measured .ady rolloff type note.
7. **Docs, acceptance test, README, final review, deploy.**
